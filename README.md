## About

This comprehensive learning resource is created by **Marimuthu Palaniappan**, a [Sencha MVP](https://www.sencha.com/mvp/), to help developers master ExtJS development.

## What is Sencha ExtJS?

[Sencha ExtJS](https://www.sencha.com) is a comprehensive JavaScript framework for building data-intensive, cross-platform web and mobile applications for any modern device.
